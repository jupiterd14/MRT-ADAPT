How to Use Model Performance

This dashboard helps you test and evaluate your ML models. Here's how to use each section:

1 Run Tests

Click "Run Tests" to automatically test your models against 2025 data. This generates predictions, compares them to actual values, and saves results.

2 Check Metrics

Look at the MAE (Mean Absolute Error) - lower is better.

3 View Results by Station

Select a station from the dropdown to see detailed results. The table shows each prediction with error and verdict.

4 Run Evaluation (Advanced)

Click "Run Evaluation" to generate a confusion matrix and classification metrics (precision, recall, F1-score). This shows where your model makes mistakes.

5 Advanced Tools

Upload CSV: Test with 2025.csv
Manual Test: Test a single specific prediction.
Chart: Visual comparison of predictions vs actuals.

Quick Tips
  • Run tests weekly to monitor if your model is drifting
  • Focus on stations with high MAE - they need retraining
